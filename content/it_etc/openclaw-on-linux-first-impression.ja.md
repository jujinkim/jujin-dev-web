# はじめに
ML、ディープラーニングに続きトランスフォーマー＆アテンション LLM AIが登場すると、世界は急速に変わり始めた。以前も遅かったわけではないが、LLM AIはもしかすると新しい産業革命であり、技術的特異点を達成できるものとして感じられるほどだ。

その中で、この LLM AIを活用して単純なチャットボットを超え、PC自体を操作できるツールが登場した。長期間開発と変更を重ね、現在に至り `Openclaw` という名前のオープンソースとして配布されているプログラムがある。

もともと注目されていたプロジェクトだったが、最近の LLM Modelの急激な発展とともに性能が急速に向上し、このツールは非常に有名になった。今ではAIに関心のある非専門家も一度は使ってみて感嘆するほど、バイラルマーケティングまでされてしまった。
