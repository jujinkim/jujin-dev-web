# 序論
ML、ディープラーニングに続き、TransformerとAttentionを用いたLLM AIが登場すると、世界は急速に変わり始めました。以前も遅くはありませんでしたが、LLM AIはもしかすると新たな産業革命であり、技術的特異点（シンギュラリティ）を達成しうるものだと感じられるほどです。

その中で、このLLM AIを活用して単なるチャットボットを超え、PC自体を簡単に操作できるツールが登場しました。その中に`Openclaw`という名前でオープンソースとして配布されているプログラムがあります。

もともと注目されていたプロジェクトでしたが、最近のLLMモデルの急激な発展と共に性能が急速に向上し、このツールは非常に有名になりました。今ではAIに関心のある非専門家たちも一度使ってみては感嘆するほど、バイラルマーケティングにまでなっています。

---
# Openclawとは
名前が二度も変わりましたが（`Clawdbot` -> `Moltbot`）、まあ歴史はこの記事では重要ではなく、簡単に言うと以下の通りです。
> ChatGPTなどのLLMモデルが直接コンピュータ全体を操作できるようにし、これを簡単に設定できるツール

実のところ、Openclawなしでも従来からこのようなことが不可能だったわけではありません。必ずしもチャットボットクライアント（`ChatGPT`など）でなくても、LLMモデルを使用できるAPIがあったり、自前でLLMを動かすことができたり（`ollama`、`gpt-oss`など）、これらにCLIまたはGUIを操作させるだけでよかったのです。`Claude Code`を筆頭に登場した`Gemini CLI`、`Codex CLI`などは、そもそもターミナルで実行するチャットボットであり、本来の目的はコーディングエージェントでしたが、実質的にCLIコマンドを直接実行できるLLMクライアントであったため、限定的ではありますがPCを制御することもできました。
