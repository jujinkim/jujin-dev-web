# はじめに
ML、ディープラーニングに続き、Transformer＆Attention LLM AIが登場すると、世界は急速に変わり始めた。以前も遅かったわけではないが、LLM AIはもしかすると新しい産業革命であり、技術的特異点を達成できるものと感じられるほどだ。

その中で、このLLM AIを活用して、単なるチャットボットを超えてPC自体を操作できるツールが登場し、長期間開発と変更を経て、現在に至り `Openclaw` という名前のオープンソースとして配布されているプログラムがある。

もともと注目されていたプロジェクトだったが、最近のLLMモデルの急激な発展とともに性能が急速に向上し、このツールは非常に有名になった。今ではAIに関心のある非専門家も一度は使ってみて感嘆するほど、バイラルマーケティングまでされてしまった。
