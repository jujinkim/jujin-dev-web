# 序論
ML、ディープラーニングに続き、トランスフォーマー＆アテンションLLM AIが登場すると、世界は急速に変わり始めた。以前も変化が遅かったわけではないが、LLM AIはもしかすると新たな産業革命であり、技術的特異点を達成できる代物であると感じられるほどだ。

その中で、このLLM AIを活用して単なるチャットボットを超え、PC自体を簡単に操作できるツールが登場した。その一つに、`Openclaw`という名前でオープンソースとして配布されているプログラムがある。

もともと注目されていたプロジェクトだったが、最近のLLMの急激な発展とともに性能が急速に向上し、このツールは非常に有名になった。今ではAIに関心のある非専門家も一度は使ってみて感嘆するほど、バイラルマーケティングまでされるようになった。

---
# Openclawとは
名前が二度も変わったが（`Clawdbot` -> `Moltbot`）、まあ歴史はこの記事では重要ではなく、簡単に言えば以下の通りだ。
> GPTなどのLLMモデルが直接コンピュータ全体を操作できるようにし、これを簡単に設定できるツール。

実はOpenclawがなくても、以前からこのようなことが不可能だったわけではない。チャットボットクライアント（`ChatGPT`など）でなくても、LLMを使用できるAPIやローカルLLMを動かすことができ（`ollama`、`gpt-oss`など）、これらがPCを操作するようにすればよかった。`Claude Code`を筆頭に登場した`Gemini CLI`、`Codex CLI`などは、最初からターミナルで実行するチャットボットで、目的はコーディングエージェントだったが、事実上CLIコマンドを直接実行できるLLMクライアントであったため、制限的ながらPCを制御することもできた。

しかし、私たちは必ずしもコンピュータの前にいなくても、遠隔で仕事をさせたいと願っていた。そのためには、SSH、MCP、権限などの複雑な設定を直接管理しなければならなかった。ある程度の複雑さを解消するためのサービス（`Omnara`など）が登場したが、これらのサービスは有料であったり、わずかな複雑さを解消するだけで決定的ではなかった。そんな中、オーストリアのある開発者が**趣味**で開発し始めた`Clawdbot`プロジェクトが、成長して口コミで広まり、`Openclaw`になった。

`Openclaw`をPCにインストールした後、非常に簡単な設定を行うだけで、LLMが自分のPCに対する制御権を持ち、TelegramなどのIMアプリを通じて非常に簡単に命令を下すことができる。単に対話をするだけでなく、自分のコンピュータでできることをメッセージングアプリを通じてさせるのだ。

例えば、Telegramを通じてコーディングをさせたり、資料調査や文書作成、メール管理、そしてウェブサーフィンやショッピングまで。ただ**メッセンジャーで自分のPCとリアルタイムで対話をしながら作業**をさせることができる。この機能のおかげで、多くの人が「自分のPCにアイアンマンのジャービスを」という表現をよく使う。つまり、OpenclawはIMアプリと自分のPCをLLMでつないでくれるゲートウェイの役割を果たすプログラムだ。

# 実行するPCの選定
OpenclawのためにMac Miniが品薄状態になるほど、多くの人がMac MiniをOpenclawのホストとして選択している。しかし、ほとんどの人は単に「Mac Miniを使わなければならない」程度にしか知らないようだった。以下の場合はMac Miniを使うべきであり、それ以外の場合はMac Miniを使う必要はない。そもそもOpenclawは「クロスプラットフォーム」ツールだ。

- Openclawを通じてiOS & macOSのネイティブアプリを開発させたい。
- 単なるテキスト＆コーディング作業ではなく、モニターやマウスまで活用してコンピュータの全機能を制御させたい。（ウェブ画面を探索し、複雑な文書を作成させ、ショッピングをするなど）
- 24/7 常に起動しておく別の低電力macOSコンピュータが必要だ。

すでにMacを持っているなら、そのまま使用中のMacにインストールしてもいい。体験として自分のMacに仮想マシンや仮想コンテナを作成して試してみよう。

特記事項として、「ローカルLLMを動かしてトークンを節約するために」Mac Miniを買うという意見もあったが、今品薄になっているのはMac Mini M4基本モデルだ。いくらMac MiniがメモリをGPUと共有しているとはいえ、たった16GBのVRAMでOpenclawに使用されるLLMを動かすのは難しい。ファインチューニングされた小さなLLMや、メディア生成のような特定の作業専用であれば納得できる。あるいは、ローカルLLMのためにメモリ64GBのMac Miniを買うなら、それは認めよう。

上記の場合でなければ、Mac Miniを買う必要はない。私もアップル系のアプリはネイティブではなくクロスプラットフォーム（KMP、Flutter、ゲームエンジン）で開発させる予定であり、まだLLMに自分のPCをすべて任せる必要はないので、Mac Miniは買わなかった。LLMはアカウントで連携するため、PCの性能が高くある必要はない。そこで、モニターが故障して倉庫に眠っていたSurface Pro 4を「穢土転生」させてリナックスサーバーを立ち上げ、そこにOpenclawをインストールした。N100の低電力ベアボーンPCも良さそうだし、少し複雑な作業（プロジェクトのビルドなど）をするなら、高性能なCPUを搭載したベアボーンPCも悪くない（ただし、最近のメモリ価格の高騰により、高性能PCよりもMac Miniの方が安い）。

OpenclawはひとまずPCを操作するすべての権限を持つため、できれば常用PCよりも別のPCにインストールすることをお勧めする。いくらLLMが賢くなったとはいえ完璧ではなく、あくまで確率推論で動作するため、ユーザーが望まない行動をいつでも起こす可能性があるからだ。これはOpenclawをインストールする際にも、強い警告文でユーザーに知らされている。

# 簡単な設定
ただインストールして、規約に同意し、Codexアカウントを連携し、Telegramボットを連携すればいい。Telegramボットは`BotFather`ボットを使えば簡単に作成・管理できる。
初期設定時（Setup wizard）に、非常に多様な設定を視覚的に簡単に行うことができ（CLIであるにもかかわらず！）、特に苦労することなく開始できた。

設定を終えてTelegramまで連携すると、自分が作成・連携したTelegramボットとチャットすれば、Openclawがそれを受け取ってPCで作業し、Telegramで結果を知らせてくれる。
本当にTelegramでChatGPTを使っているような感じだが、それが今や自分のPCを使っているのだ。

# 作業の感想
普段使っているIMメッセージングアプリのGUIで、まるで友人と会話するように自分のPCと対話する感覚が良かった。
その他、各種複雑な設定（Skills、独自のCronjob、その他数百の設定）やプラグインをサポートしており、これらをダッシュボード（WebUI）で比較的簡単に設定・管理できるのが非常に良かった。やはりGUIがCLIより普及するのは当然だ。
