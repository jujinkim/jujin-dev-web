# はじめに
ML、ディープラーニングに続き、トランスフォーマー＆アテンションLLM AIが登場すると、世界は急速に変わり始めた。以前も変化が遅かったわけではないが、LLM AIはもしかすると新しい産業革命であり、技術的特異点を達成できるものだと感じられるほどだ。

その中で、このLLM AIを活用して単純なチャットボットを超え、PC自体を簡単に操作できるツールが登場し、その中に `Openclaw` という名前のオープンソースで配布されているプログラムがある。

もともと注目されていたプロジェクトだったが、最近のLLMの急激な発展とともに性能が急速に向上し、このツールは非常に有名になった。今ではAIに関心のある非専門家も一度は使ってみて感嘆するほど、バイラルマーケティングまで広まっている。

---
# Openclawとは
名前が2回も変わったが（`Clawdbot` -> `Moltbot`）、まあ歴史はこの記事では重要ではなく、簡単に言うと以下の通りだ。
> GPTなどのLLMモデルが直接コンピュータ全体を操作できるようにし、これを簡単に設定できるツール。

実はOpenclawがなくても、従来からこのようなことが不可能だったわけではない。チャットボットクライアント（`ChatGPT` など）でなくてもLLMを使用できるAPIやローカルLLMを動かすことができ（`ollama`、`gpt-oss` など）、これらがPCを操作するようにすればよかったのだ。`Claude Code`を筆頭に登場した `Gemini CLI`、`Codex CLI` などは、最初からターミナルで実行するチャットボットであり、目的はコーディングエージェントだったが、事実上CLIコマンドを直接実行できるLLMクライアントであったため、制限的ながらもPCを制御することができた。

しかし、私たちは必ずしもコンピュータの前にいなくても、遠隔で仕事をさせることを望んでいた。このためにはSSH、MCP、権限など複雑な設定を直接管理しなければならなかった。ある程度の複雑さを解消するためのサービス（`Omnara` など）が登場したが、これらのサービスは有料であったり、わずかな複雑さを解消するだけで決定的ではなかった。そんな中、オーストリアのある開発者が**趣味**で開発し始めた `Clawdbot` プロジェクトが成長し、口コミで広がって `Openclaw` になった。

`Openclaw` をPCにインストールした後、非常に簡単な設定を行うだけで、LLMが自分のPCに対する制御権を持ち、TelegramなどのIMアプリを通じて非常に簡単に命令を下すことができる。単に対話するだけでなく、自分のコンピュータでできることをメッセージングアプリを通じてさせるのである。

例えば、Telegramを通じてコーディングをさせたり、資料調査および文書作成、メール管理、そしてウェブサーフィンやショッピングまで。ただ**メッセンジャーで自分のPCとリアルタイムで対話をしながら作業**をさせることができる。この機能のため、多くの人が「自分のPCにアイアンマンのジャーヴィスを」という表現をよく使う。つまり、OpenclawはIMアプリと自分のPCをLLMで繋ぐゲートウェイの役割を果たし、それを超えて各種スキルやプラグイン、設定などを操作しやすく提供し、セッションメモリ機能を別途サポートする統合AIエージェントプログラムである。

# 実行するPCの選定
OpenclawのせいでMac miniが品薄になるほど、多くの人がMac miniをOpenclawのホストとして選択している。しかし、ほとんどの人はただ「Mac miniを使わなければならない」程度にしか思っていないようだった。以下の場合にはMac miniを使うべきであり、それ以外の場合にはMac miniを使う必要はない。そもそもOpenclawは「クロスプラットフォーム」ツールである。

- Openclawを通じてiOS & macOSのNativeアプリを開発させたい。
- モニターやマウスまで活用して、コンピュータの全機能を制御させたい（ウェブ画面を探索し、複雑な文書を作成させ、ショッピングをするなど）。
- 24時間365日常に起動しておく、別の低電力macOSコンピュータが必要だ。
- Macが欲しいが口実が必要だ。

すでにMacを持っているなら、今使っているMacにインストールしてもいい。体験として、自分のMacに仮想マシンや仮想コンテナを作成して試してみよう。

特筆すべき点として、「ローカルLLMを動かしてトークンを節約するために」Mac miniを買うという意見もあったが、今品薄になっているのはMac mini M4の基本モデルだ。いくらMac miniがRAMをGPUと共有しているとはいえ、たった16GBのVRAMでOpenclawに使用されるLLMを動かすのは難しい。ファインチューニングされた小さなLLMや、メディア生成などの特定の作業専用ならあり得る。あるいは、ローカルLLMのためにRAM 64GBのMac miniを買うなら納得だ。

上記の場合でなければ、あえてMac miniを買う必要はない。私もApple系のアプリはネイティブではなくクロスプラットフォーム（kmp、flutter、ゲームエンジン）で開発させる予定だし、まだLLMに自分のPCをすべて任せる必要はないので、Mac miniは買わなかった。LLMはアカウントで連携するため、PCの性能が高くある必要はない。そこで、モニターが故障して倉庫に眠っていたSurface Pro 4を復活させ（穢土転生）、Linuxサーバーを立ち上げてそこにOpenclawをインストールした。N100の低電力ベアボーンPCも良さそうだし、少し複雑な作業（プロジェクトのビルドなど）をするなら、高性能CPUを搭載したベアボーンPCも悪くない（ただし、最近のRAM価格の高騰により、高性能PCよりもMac miniの方が安い）。

OpenclawはひとまずPCを操作するすべての権限を持つため、できれば常用PCよりも別のPCにインストールすることをお勧めする。いくらLLMが賢くなったとはいえ完璧ではなく、あくまで確率推論で動作するため、ユーザーが望まない行動をいつでも起こす可能性があるからだ。これはOpenclawをインストールする際にも、強い警告文でユーザーに通知されている。

# 簡単な設定
ただインストールして、規約に同意し、Codexアカウントを連携させ、Telegramボットを連携させればいい。Telegramボットは `BotFather` ボットを使えば簡単に作成・管理できる。
初期設定時（Setup wizard）に、非常に多様な設定を視覚的に簡単に行うことができ（CLIなのに！）、特に苦労することなく開始できた。

設定を終えてTelegram（または他のメッセージングアプリ）まで連携させると、自分が作成して連携させたTelegramボットとチャットすれば、Openclawがそれを受け取ってPCで作業し、Telegramで結果を教えてくれる。
本当にTelegramでChatGPTを使っているような感じだが、それが今や自分のPCを使っているのだ。

# 作業後の感想
普段使っているIMメッセージングアプリのGUIで、まるで友達と会話するように自分のPCと対話する感覚が良かった。
その他、各種複雑な設定（Skills、独自のCronjob、その他数百の設定）やプラグインをサポートしており、それをダッシュボード（WebUI）で比較的簡単に設定・管理できるのが非常に良かった。やはり、GUIがCLIより流行るのは当然だ。

さらに、一般的なAI使用時にはチャットごとにセッションが個別に生成され、そのセッションが長くなると徐々に性能が低下するが、Openclawは独自のメモリ管理ソリューションにより、一つのセッションで継続して複数の作業を行うことができる。内部的にコンテキストを切り替え続け、必要な情報だけを保存しているようだが、本当に人に仕事をさせている気分だ。

# 結論

とりあえず、今騒がれているのは大げさな面もある。
しかし、「便利だ」という観点からは支持したい。
技術の発展＋面倒くさがりが作り出した便利なツール。

ただし、自動化を自然言語で処理するツールであるだけに、気をつけないと作業が内部で凄まじく累積して実行される。これは、うっかりしている間にトークンが狂ったように消費されるという意味だ。したがって、いくら自分がCodex Proバージョンを使用していたとしても、Cronjobなどを管理し、セッションおよびトークンの管理をしっかり行わなければならない。単にメモリ管理とエージェント管理、IM連携を便利に提供するツールであることを忘れてはならない。特に他のLLM（Claude、Gemini）も使用しているなら、OpenclawのエージェントはCodexで処理させ、そのエージェントが実際の作業を行う際にClaude/Gemini CLIを使用するようにして、トークン消費を分散させ、より賢く仕事をさせるのも良い方法だろう。

急に記事を書くのが面倒になったので（はぁ、これがAIの副作用だ）、とりあえず急いで切り上げたが、後で余裕がある時に内容を補充する。
