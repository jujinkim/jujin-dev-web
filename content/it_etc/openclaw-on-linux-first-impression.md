# 서론
ML, 딥러닝에 이어 트랜스포머&어텐션 LLM AI가 등장하자 세상은 빠르게 바뀌기 시작했다. 이전에도 변화가 느린건 아니었지만, LLM AI는 어쩌면 새로운 산업혁명이자 기술적 특이점을 달성할 수 있는 물건으로 느껴질 정도이다.

그 중, 이 LLM AI를 활용하여 단순 챗봇을 너머 PC 자체를 쉽게 조작할 수 있는 도구가 등장했고, 그 중  `Openclaw` 라는 이름의 오픈소스로 배포되는 프로그램이 있다.

원래도 주목받았던 프로젝트였지만 최근 LLM의 급격한 발전과 함께 성능이 빠르게 향상되어 이 툴이 굉장히 유명해졌고 이제는 AI에 관심이 있는 비 전문가들도 한 번 쯤 써보고는 감탄할 정도로 바이럴 마케팅까지 되어버렸다.

# Openclaw란
이름이 두 번이나 바뀌었는데(`Clawdbot` -> `Moltbot`), 뭐 역사는 이 글에서는 중요하지 않고, 간단히 말하면 아래와 같다
> GPT 등의 LLM 모델이 직접 컴퓨터 전체를 조작할 수 있게 하고, 이를 쉽게 설정할 수 있는 도구

사실 오픈클로 없이 기존에도 이런 짓이 불가능한 것은 아니었다. 챗봇 클라이언트(`ChatGPT` 등)가 아니어도 LLM 사용할 수 있는 API 또는 로컬 LLM을 돌릴 수 있었고(`ollama`, `gpt-oss` 등), 이들이 PC를 조작하게만 해주면 되었었다. `Claude Code`를 필두로 등장한 `Gemini CLI`, `Codex CLI` 들은 아예 터미널에서 실행하는 챗봇으로, 목적은 코딩 에이전트였지만 사실상 CLI 명령어를 직접 수행할 수 있는 LLM 클라이언트였기에 제한적으로나마 PC를 제어할 수도 있었다.

하지만 우리는 꼭 컴퓨터 앞이 아니어도 원격으로 일을 시키기를 원했다. 이를 위해서는 SSH, MCP, 권한 등 복잡한 설정들을 직접 관리해야했다. 어느정도 복잡함을 해소하기 위한 서비스들(`Omnara` 등 )이 등장했으나 이 서비스들은 유료이거나 약간의 복잡함만 해소시켜줬을 뿐 결정적이지는 못했다. 그 와중에 오스트리아의 한 개발자가 **취미**로 개발하기 시작한 `Clawdbot` 프로젝트가, 성장하고 입소문을 타서 `Openclaw`가 되었다.

`Openclaw` 를 PC에 설치한 후, 아주 간단한 설정만 거치면 LLM이 내 PC에 대한 제어권을 가져가며, 텔레그램 등의 IM앱들을 통해 아주 쉽게 명령을 내릴 수 있다. 단순히 대화만 하는게 아닌, 내 컴퓨터로 할 수 있는 일을 메세징 앱을 통해 시키는 것이다.

가령 텔레그램을 통해 코딩을 시키거나 자료조사 및 문서 작성, 이메일 관리, 그리고 웹 서핑과 쇼핑까지. 그저 **메신저로 내 PC와 실시간으로 대화를 하면서 작업**을 시킬 수 있다. 이 기능 때문에 많은 사람들이 "내 PC에 아이언맨의 자비스를" 라는 표현을 많이 쓴다. 즉, 오픈클로는 IM앱과 내 PC를 LLM으로 연결시켜주는 관문 역할을 하며, 이를 너머 각종 스킬과 플러그인, 설정 등을 조작하기 쉽게 제공하고 세션 메모리 기능을 별도로 지원하는 통합 AI Agent 프로그램이다.

# 실행할 PC 선정
오픈클로때문에 Mac Mini가 품귀현상이 발생할 정도로 많은 사람이 맥미니를 오픈클로의 호스트로 선택한다. 하지만 대부분의 사람들은 그냥 "맥미니를 써야만 한다" 정도로만 아는 것 같았다. 아래의 경우에는 맥미니를 써야하며, 그 외의 경우에는 맥미니를 쓸 필요가 없다. 애초에 오픈클로는 "크로스 플랫폼" 툴이다.

- Openclaw를 통해 iOS & macOS 의 Native 앱을 개발시키고 싶다.
- 모니터와 마우스까지 활용하여 컴퓨터의 모든 기능을 제어시키고 싶다. (웹 화면을 탐색하고, 복잡한 문서를 작성시키고, 쇼핑을 하는 등)
- 24/7 항상 켜둘 별도의 저전력 macOS 컴퓨터가 필요하다.
- mac이 가지고 싶은데 핑계가 필요하다.

이미 맥이 있으면 그냥 사용중인 맥에 설치해도 된다. 체험으로 본인 맥에 가상머신 또는 가상컨테이너를 만들고 체험해보자.

특이사항으로 "로컬 LLM을 돌려서 토큰을 아끼기 위해" 맥미니를 산다는 의견도 있었는데, 지금 품귀현상이 발생한건 맥미니 M4 기본형이다. 아무리 맥미니가 램을 GPU와 공유한다지만, 고작 16gb vram으로 오픈클로에 쓰일 LLM을 돌리기는 어렵다. 파인튜닝된 작은 LLM 또는 미디어 생성같은 특정 작업 전용이라면 그럴 법 하다. 또는 로컬 LLM을 위해 램 64gb짜리 맥미니를 산다면 그건 인정.

위 경우가 아니라면 굳이 맥미니를 살 필요가 없다. 나도 애플쪽 앱은 네이티브가 아닌 크로스플랫폼(kmp, flutter, 게임엔진) 으로 개발시킬 예정이고, 아직 LLM에게 내 PC를 모두 맡길 필요가 없어서 맥미니를 사지 않았다. LLM은 계정으로 연결하기 때문에 PC 성능이 좋을 필요가 없다. 그래서 모니터가 고장나 창고에 처박아놓은 서피스프로4를 예토전생시켜서 리눅스 서버를 올리고 여기에 오픈클로를 설치했다. N100 저전력 베어본 PC도 좋아보이며, 좀 복잡한 작업 (프로젝트 빌드 등)을 한다면 고성능 CPU가 들어간 베어본 PC도 괜찮다(하지만 요즘 램값 이상으로 인해 고성능 PC보다는 맥미니가 더 싸다).

오픈클로는 일단 PC를 조작하는 모든 권한을 가져가기 때문에, 가급적이면 실사용 PC보다는 별도의 PC에 설치하기를 권장한다. 아무리 LLM이 똑똑해졌다지만 완벽하지는 않으며, 어디까지나 확률 추론으로 작동하기 때문에 사용자가 원하지 않는 행동을 언제든지 할 수 있기 때문이다. 이는 오픈클로를 설치할 때에도 강한 경고문으로 사용자에게 알리고 있다.

# 간단한 설정 
그냥 깔고, 약관 동의하고, Codex 계정 연결하고, 텔레그램 봇 연결하면 된다. 텔레그램 봇은 `BotFather` 봇을 사용하면 편하게 만들고 관리할 수 있다.
초기 설정시(Setup wizard)에 아주 다양한 설정을 시각적으로 쉽게 할 수 있어서(CLI임에도!) 별다른 어려움 없이 시작할 수 있었다.

설정을 끝내고 텔레그램(또는 다른 메세징 앱)까지 연결하면, 내가 만들고 연결한 텔레그램 봇과 채팅하면 오픈클로가 받아서 PC에서 작업하고 텔레그램으로 결과 알려준다.
진짜 텔레그램으로 챗지피티쓰는느낌인데, 그게 이제 내 PC를 사용하는.

# 작업 후기
평소 쓰는 IM메세징 앱 GUI로, 마치 친구와 대화하듯 내 PC와 대화한다는 느낌이 좋았다.
그 외 각종 복잡한 설정들(Skills, 자체 Cronjob, 그 외 수백개의 설정)과 플러그인을 지원하고 있고, 이를 대쉬보드(WebUI)에서 비교적 쉽게 설정하고 관리할 수 있다는게 아주 좋았음. GUI가 CLI보다 흥할 수 밖에 없다 역시.

게다가 일반적인 AI 사용시에는 채팅마다 세션이 따로 생성되고 해당 세션이 길어지면 점점 성능이 떨어지는데, 오픈클로는 자체적인 메모리 관리 솔루션으로 한 세션에서 계속 여러 작업을 할 수가 있다. 내부적으로 컨텍스트를 계속 바꾸고 필요한 정보만 저장하는 모양인데, 정말로 사람에게 일을 시키는 기분이다.

# 결론

일단 지금 시끄러운건 호들갑이 맞다.
하지만 "편하다" 는 관점에서 손을 들어주고 싶다.
기술의 발전 + 귀차니즘이 만들어낸 편리한 도구.

다만, 자동화를 자연어로 처리하는 툴인만큼, 신경을 쓰지 않으면 작업이 내부에서 엄청나게 누적되어 돌아간다. 이 뜻은 앗차하는사이 토큰이 미친듯이 소모된다는 뜻이다. 따라서 아무리 본인이 Codex Pro버전을 사용하더라도 Cronjob 등을 관리하고, 세션 및 토큰 관리를 잘 해줘야한다는 뜻이다. 그저 메모리 관리와 에이전트 관리, IM 연결을 편하게 제공하는 툴이라는 것을 잊으면 안된다. 특히 다른 LLM(Claude, Gemini)도 사용중이라면, Openclaw의 Agent들은 Codex로 처리하고 해당 Agent가 실제 작업을 할 때 Claude/Gemini cli를 사용하게끔 하여 토큰 소모를 분할하고 더 똑똑하게 일처리를 시키는 것도 좋은 방법일 것이다.

갑자기 글 쓰기 귀찮아서(하 이게 다 AI의 부작용이다) 일단은 급하게 끝냈는데, 나중에 여유로울 때 내용을 더 채워넣겠다.
