# 서론
ML, 딥러닝에 이어 트랜스포머&어텐션 LLM AI가 등장하자 세상은 빠르게 바뀌기 시작했다. 이전에도 느린건 아니었지만, LLM AI는 어쩌면 새로운 산업혁명이자 기술적 특이점을 달성할 수 있는 물건으로 느껴질 정도이다.

그 중, 이 LLM AI를 활용하여 단순 챗봇을 너머 PC 자체를 쉽게 조작할 수 있는 도구가 등장했고, 그 중  `Openclaw` 라는 이름의 오픈소스로 배포되는 프로그램이 있다.

원래도 주목받았던 프로젝트였지만 최근 LLM Model의 급격한 발전과 함께 성능이 빠르게 향상되어 이 툴이 굉장히 유명해졌고 이제는 AI에 관심이 있는 비 전문가들도 한 번 쯤 써보고는 감탄할 정도로 바이럴 마케팅까지 되어버렸다.

# Openclaw란
이름이 두 번이나 바뀌었는데(`Clawdbot` -> `Moltbot`), 뭐 역사는 이 글에서는 중요하지 않고, 간단히 말하면 아래와 같다
> ChatGPT 등의 LLM 모델이 직접 컴퓨터 전체를 조작할 수 있게 하고, 이를 쉽게 설정할 수 있는 도구

사실 오픈클로 없이 기존에도 이런 짓이 불가능한 것은 아니었다. 꼭 챗봇 클라이언트(`ChatGPT` 등)가 아니어도 LLM 모델을 사용할 수 있는 API가 있었거나 자체적으로 LLM을 돌릴 수 있었고(`ollama`, `gpt-oss` 등), 이들이 CLI 또는 GUI를 조작하게만 해주면 되었었다. `Claude Code`를 필두로 등장한 `Gemini CLI`, `Codex CLI` 들은 아예 터미널에서 실행하는 챗봇으로, 본 목적은 코딩 에이전트였지만 사실상 CLI 명령어를 직접 수행할 수 있는 LLM 클라이언트였기에 제한적으로나마 PC를 제어할 수도 있었다.
